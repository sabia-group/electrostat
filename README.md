# Electrostat
This repository holds example input files for electrochemical simulations using the electrostat in LAMMPS/ELECTRODE.

The directory `lammps-electrode-source-code` contains the LAMMPS code with the new additions to the ELECTRODE package, including the electrostat.

The directory `md-inputs` then contains the LAMMPS input files, force-field parameters, atomic geometries and examples of output from the calculation presented in our publication. Follow the instructions in the [LAMMPS manual](https://docs.lammps.org/Manual.html).
