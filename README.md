# Electrostat
This repository holds example input files for electrochemical simulations using the electrostat in LAMMPS/ELECTRODE.

The directory `lammps-electrode-source-code` contains the LAMMPS code with the new additions to the ELECTRODE package, including the electrostat. Follow the instructions in the [LAMMPS manual](https://docs.lammps.org/Manual.html) to compile and use it.

The directory `md-inputs` then contains the LAMMPS input files, force-field parameters, atomic geometries and examples of outputs from the calculations presented in our publication.
It contains the following subdirectories
- `Fig2-ensemble-equivalences` 
- `Fig3-ensemble-equivalences`
- `Fig4-ion-association`
- `Fig5-diffusion`
- `Fig6-size-dependence`
- `FigS1-j-term-approximation`
- `FigS2-integration-order`
